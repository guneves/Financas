- **finance-guard**, found directly by `subagent_type`, reported no cross-user leak and no path to a

    in flight could be overwritten, removed or brought back. `OutboxStore.removeIfUnchanged` /
    `replaceIfUnchanged` now act only on the version that was sent.

### Learned
- **The tailnet name is not the Windows hostname.** Read it with `tailscale status --json`, from
  `Self.DNSName`. `tailscale.exe` is in `C:\Program Files\Tailscale\`, not on PATH.
- **Capacitor 8 specifics:**
  - `SystemBars` is built into `@capacitor/core`/`android`; `@capacitor/status-bar` is not needed;
  - `insetsHandling` is `native` / `css` / `disable` (`css` also injects `--safe-area-inset-*`);
  - it pads the WebView for the IME, so `adjustResize` behaviour comes for free;
  - `BridgeActivity.onCreate` sets `AppTheme.NoActionBar` itself and never calls
    `installSplashScreen()`, so the Android 12+ system splash reads the launch theme's
    `windowSplashScreen*`.
- **Plugins of our own** are registered in `MainActivity` with `registerPlugin(X.class)` *before*
  `super.onCreate`. JS reaches them with `registerPlugin('Name')` from `@capacitor/core`.
- **The Bash tool collapses `\\` inside a heredoc, even a quoted one.** A Python edit script
  written that way turned `\b` and `\f` into control characters in a Markdown file. Write such
  scripts with the Write tool (as the memory note says), then grep for `[\x00-\x08\x0b\x0c]`.
- **Under `$ErrorActionPreference = 'Stop'`, Windows PowerShell throws on a native command's
  stderr when it is redirected with `2>&1`.** `build-apk.ps1` switches to `Continue` around
  `adb install`.
- Carried:
  - `core.autocrlf` is true;
  - `tmp_path` fails here, so use `tempfile.mkdtemp(dir=...)`;
  - run `python -m pytest` plain;
  - `node --test` wants the glob;
  - open `finance.db` read-only with `file:<path>?mode=ro`;
  - the phone-walk recipe (scratch `serve.py`, port 5003, Vite on 5176, signup needs `username`)
    is in git history: `git log -p docs/handoff.md`.
